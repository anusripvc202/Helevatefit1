# Helevate.fit

> Premium Community-First Fitness & Longevity Coaching Platform.

## 🚀 Features

- **Architectural Dark Navy Glassmorphic Design:** Modern CAD-inspired aesthetic with luminous teal accents.
- **Sticky Glassy Navbar:** Pinned to top with zero gap, matching hero container width with subtle glass backdrop-filter.
- **Concentric Bowtie Wireframe Watermarks:** Responsive vector brand motifs integrated across Hero, Services, Plans, Founder, and CTA sections.
- **Interactive Multi-Layered Hover Effects:** Dynamic 3D elevation on cards with coordinated watermark parallax shifts.
- **Responsive Layout:**
  - Full-screen desktop view.
  - Horizontal swipeable coach cards track on mobile with scroll-snap.
  - Staggered non-overlapping gym clubhouse pins.
  - Scroll-triggered GSAP animations triggering smoothly on both scroll up and scroll down.

## 🛠 Tech Stack

- **Structure:** Semantic HTML5
- **Styling:** Vanilla CSS (Custom Design System, Flexbox, CSS Grid)
- **Animation & Motion:** GSAP 3.12+ (ScrollTrigger)
- **Icons:** Bootstrap Icons, Lucide Icons, FontAwesome
- **Local Server:** Pure Node.js HTTP Server (`server.js`)

## 🏃 Running Locally

To run the local development server:

```bash
node server.js
```

Then visit [http://localhost:8000](http://localhost:8000) in your browser.
